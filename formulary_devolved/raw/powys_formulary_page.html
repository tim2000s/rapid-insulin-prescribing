      Formulary

      To view the PTHB formulary : Formulary (wales.nhs.uk)

      Prescribing concern form

      Prescribing Concern Form

      The form should be used:

      • If you wish to report any concerns regarding a specialist prescriber requesting that prescribing of a medication is transferred to primary care.

      Formulary enquiries

      If you would like to request a new product to PTHB formulary, an existing medicine for a different indication or to change a formulary status of an existing product please contact newmedicines.powys@wales.nhs.uk
